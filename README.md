# 🧪 AI Chemistry Lab

一个面向高中教学的虚拟化学实验平台，支持拖拽试剂、实时动画反馈、教师控制台和任务模式。

## ✨ 功能特点

- **拖拽试剂到烧杯**：自动配对反应，支持 30+ 种常见试剂。
- **超仿真动画系统**：
  - 发热反应：火焰 + 热浪扭曲
  - 沉淀反应：沉淀从底部生长 + 颗粒沉降
  - 产气反应：连续密集气泡上升
  - 置换反应：金属光泽闪烁
  - 液体颜色动态变化
- **智能提示**：当两种试剂不反应时，弹出对话框并建议可反应的试剂。
- **教师控制台**：实时记录所有实验操作，便于课堂点评。
- **任务模式**：内置沉淀、产气、置换、中和四种任务，自动统计完成进度。
- **AI讲解**：点击按钮获取当前反应的科学原理解析。
- **二维码课堂入口**：生成当前页面二维码，学生扫码即可进入。
- **玻璃拟态 UI**：毛玻璃效果、深色渐变背景，现代美观。

## 🚀 部署到 GitHub Pages

1. 下载本项目所有文件，保持目录结构不变。
2. 在 GitHub 上新建一个 **Public** 仓库（例如 `ai-chemistry-lab`）。
3. 将整个文件夹内容上传到仓库根目录。
4. 进入仓库 **Settings → Pages**，在 "Branch" 下选择 `main`，文件夹选 `/ (root)`，点击 **Save**。
5. 等待约1分钟，访问 `https://你的用户名.github.io/仓库名/` 即可使用。
